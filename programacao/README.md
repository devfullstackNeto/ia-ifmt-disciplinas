```python
def calcular_media(notas: list[float]) -> float:
    """Calcula a média de uma lista de notas."""

    if not notas:
        return 0.0

    return sum(notas) / len(notas)


def exibir_resultado(media: float) -> None:
    """Exibe a situação do estudante."""

    if media >= 6:
        print("Situação: aprovado")
    else:
        print("Situação: em recuperação")


notas = [7.5, 8.0, 6.5]
media = calcular_media(notas)

print(f"Média: {media:.2f}")
exibir_resultado(media)
```

## Comentários e documentação

Comentários devem explicar decisões importantes, e não repetir o que já está evidente no código.

Evite:

```python
# Soma dois números
resultado = numero_1 + numero_2
```

Prefira:

```python
# A taxa administrativa é incorporada antes da aplicação do desconto.
valor_total = valor_base + taxa_administrativa
```

Funções relevantes deverão utilizar docstrings:

```python
def calcular_desconto(valor: float, percentual: float) -> float:
    """Retorna o valor final após a aplicação do desconto."""

    return valor - valor * percentual / 100
```
